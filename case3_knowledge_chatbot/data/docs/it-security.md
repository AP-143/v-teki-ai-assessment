# IT Security Standard

## Passwords
Passwords must have at least 12 characters and must be changed every 180 days. Never reuse a password from another system or share it with anyone, including IT staff.

## Multi-factor authentication
Multi-factor authentication (MFA) is mandatory for email, VPN and the HR portal.

## Phishing and incidents
Report suspected phishing emails within 1 hour using the "Report phishing" button or by emailing security@nds.example. Report a lost or stolen laptop or phone to the IT service desk within 24 hours.

## Software and devices
USB storage devices are blocked on company laptops. Install software only through the IT service desk.
